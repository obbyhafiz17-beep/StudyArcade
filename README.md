# StudyArcade

**Belajar Jadi Lebih Seru!** Aplikasi belajar bergaya game untuk pelajar SMP kelas 7–9.

## Tech stack
- Next.js App Router + TypeScript
- Tailwind CSS v4 dan CSS responsif
- Lucide React
- Local-first progress storage (localStorage), tanpa login atau API berbayar untuk MVP

## Menjalankan secara lokal
1. Install Node.js versi LTS.
2. Jalankan `npm install`.
3. Jalankan `npm run dev`.
4. Buka `http://localhost:3000`.

## Fitur MVP
- Dashboard gamifikasi XP, level, streak.
- Katalog pelajaran Matematika, IPA, Informatika, Bahasa Inggris.
- Rute pelajaran, flashcards, tantangan, progres, pencapaian.
- Penyimpanan progres lokal tanpa akun.

## Catatan
Progres tersimpan hanya pada browser/perangkat yang sedang dipakai. Belum ada sinkronisasi antarperangkat.
